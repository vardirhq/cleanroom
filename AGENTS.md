# AGENTS.md

## Working rules

- Review `TODO.md` before starting substantial work.
- Update `TODO.md` when tasks are added, started, completed, split, or removed.
- When making a meaningful code or docs change, reflect that progress in `TODO.md` in the same turn.
- When a change is worthy of a release/version change, bump the project version in the same turn instead of leaving version metadata stale.
- Keep the checklist practical: prefer concrete, checkable items over vague notes.
- If work lands that is not yet tracked, add it to `TODO.md` before finishing.
